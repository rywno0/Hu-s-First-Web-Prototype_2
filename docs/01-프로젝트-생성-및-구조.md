# 01. 프로젝트 생성 및 구조

## 목적
Antigravity가 요구사항을 해석하지 않고 같은 구조의 최소 웹 프로젝트를 만들도록 한다.

## 고정 스택과 범위
- Node.js 런타임에서 실행되는 Vercel 서버리스 API와 정적 프론트엔드.
- HTML/CSS/바닐라 JavaScript만 사용한다. 프론트엔드 프레임워크, CSS 프레임워크, 별도 분석 API를 임의로 추가하지 않는다.
- 입력과 결과를 브라우저 로컬/원격 DB에 저장하지 않는다. Supabase는 이번 버전에서 연결하지 않는다.
- Vercel의 현재 Node.js 런타임과 배포 규격에 맞춘다. 지원 버전은 프로젝트 생성 시 Vercel 공식 설정을 확인해 고정하고 README에 기록한다.

## 생성 파일
필요한 최소 구조를 만들고 기존 파일은 보존한다.
```text
/
  index.html
  styles.css
  app.js
  api/analyze.js
  package.json
  vercel.json (필요할 때만)
  .env.example
  .gitignore
  README.md
  AGENTS.md
  PRD.md
  docs/ (이 문서 세트)
```

## 설정
- `OPENAI_API_KEY`는 Vercel 프로젝트 환경 변수 및 로컬 비밀 환경에만 둔다.
- 모델 식별자는 `OPENAI_MODEL` 환경 변수로 설정 가능하게 하며, 지원되는 모델을 README에 기재한다. 임의로 오래된 모델명을 고정하지 않는다.
- `.env.example`에는 실제 키 대신 `OPENAI_API_KEY=replace-me` 같은 예시만 둔다. `.env*` 비밀 파일은 Git에서 제외한다.
- 요청 제한을 고려해 기본 최대 입력을 2,000자(Unicode 코드 포인트 기준)로 둔다. 변경 시 API와 UI 제한 및 안내 문구를 함께 바꾼다.

## 생성 완료 기준
- 로컬에서 정적 페이지가 제공되고 서버 함수 경로가 Vercel API로 호출된다.
- API 키 없이도 정적 화면이 표시된다. 분석 요청 시 서버가 설정 오류를 안전한 오류 응답으로 반환한다.
- 실행/환경변수/배포 방법이 README에서 비전공자도 따라 할 수 있도록 단계별로 설명된다.

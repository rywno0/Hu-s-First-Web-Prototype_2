# 05. 환경변수, Supabase 및 Vercel

## 환경변수
- `OPENAI_API_KEY`: 필수 비밀. 로컬 `.env.local` 또는 Vercel 환경 변수 화면에서만 설정한다.
- `OPENAI_MODEL`: 필수 또는 프로젝트가 정한 기본값. 선택 모델 및 응답 형식 호환성을 README에 설명한다.
- 비밀값을 `NEXT_PUBLIC_` 등 브라우저 공개 접두사로 만들지 않는다. 실제 값이 든 파일을 커밋하지 않는다.

## Supabase 결정
- 현재 기능은 일회성 요청/응답이므로 Supabase DB 연결을 만들지 않는다. 환경 변수, 테이블, 사용자 입력 저장을 추가하지 않는다.
- 사용자가 추후 기록 저장을 요구하면 별도 설계로 전환한다. 그때 최소 데이터, 저장 목적, 보존기간, 삭제 방식, 사용자 동의, RLS 정책, 키 분리를 먼저 명세한다.

## 로컬 실행
1. Node.js 설치 여부와 버전을 확인한다.
2. 프로젝트 루트에서 `npm install` (잠금 파일과 일치하는 명령) 실행.
3. `.env.example`을 참고해 로컬 환경 변수 파일을 만들고 실제 OpenAI 키를 입력한다. 이 파일은 공유/커밋하지 않는다.
4. Vercel CLI 개발 서버 또는 프로젝트에 맞는 로컬 서버 명령으로 프론트와 API를 함께 실행한다. 실제 명령을 README에 명시한다.
5. 브라우저에서 화면을 열고 정상/오류 흐름을 확인한다.

## Vercel 배포
- 저장소를 Vercel 프로젝트에 연결하고 프로젝트 루트 및 프레임워크 없음/Node API 설정을 확인한다.
- `OPENAI_API_KEY`, `OPENAI_MODEL`을 Preview와 Production 각각 필요한 환경 범위에 등록한다. 값은 코드/로그/커밋에 넣지 않는다.
- Preview 배포에서 검증 문서의 체크리스트를 통과한 뒤 Production에 배포한다.
- 빌드/함수 로그에서 비밀값과 사용자 입력이 출력되지 않는지 확인한다.
- 분석 API는 서버리스 함수 호출로 동작해야 하며, 정적 호스팅 전용 설정으로 API 경로가 무시되지 않게 한다.

# 여운(餘韻) 감성 분석기

> 사용자가 입력한 한국어 문장의 감성 방향(긍정, 부정, 중립)과 신뢰도, 짧은 분석 근거를 안내하는 반응형 웹 서비스입니다.

---

## 📌 주요 특징

- **단일 페이지 반응형 웹 UI:** 모바일과 데스크톱 화면에 최적화된 다크 테마 디자인 (#08090b 및 형광 라임 #B7F21A 포인트)
- **OpenAI 기반 실시간 감성 분석:** GPT 모델을 활용한 정밀한 한국어 감성 분석 (긍정 / 부정 / 중립)
- **보안 최우선 설계:** API 비밀 키는 브라우저에 절대 노출되지 않으며, 서버 측 엔드포인트(`/api/analyze`)에서 안전하게 호출
- **Supabase 데이터베이스 마이그레이션 지원:** RLS(행 단위 보안) 및 데이터 무결성 제약조건이 적용된 SQL 스크립트 제공

---

## 🛠️ 기술 스택

- **Frontend:** HTML5, CSS3, Vanilla JavaScript (외부 프레임워크 미사용)
- **Backend:** Node.js (Vercel Serverless Function 호환)
- **AI Engine:** OpenAI API (`gpt-4o-mini`)
- **Database (선택):** Supabase (PostgreSQL with RLS)
- **배포:** Vercel

---

## 🚀 로컬 컴퓨터에서 실행하는 방법

코딩 초보자분들도 아래의 3단계만 따라 하시면 내 컴퓨터에서 바로 실행해 보실 수 있습니다!

### 1단계: 필수 패키지 설치
터미널(PowerShell 또는 명령 프롬프트)을 열고 프로젝트 폴더 경로에서 다음 명령어를 입력합니다:
```bash
npm install
```
*(OpenAI 통신 및 환경 변수 처리에 필요한 가벼운 라이브러리들이 자동으로 설치됩니다.)*

### 2단계: 환경 변수(.env) 설정 확인
프로젝트 루트에 있는 `.env` 파일에 발급받으신 OpenAI API 키가 정상적으로 적혀 있는지 확인합니다:
```env
OPENAI_API_KEY=sk-실제_API_키_입력
OPENAI_MODEL=gpt-4o-mini
```

### 3단계: 로컬 서버 실행
다음 명령어를 입력하여 서버를 실행합니다:
```bash
npm start
```
서버가 시작되면 터미널에 아래와 같은 안내가 출력됩니다:
```text
====================================================
🚀 [여운 감성 분석기] 로컬 서버가 정상 작동 중입니다!
🌐 브라우저 주소: http://localhost:3000
💡 서버를 종료하려면 터미널에서 Ctrl + C 를 누르세요.
====================================================
```

### 4단계: 브라우저에서 열기
크롬(Chrome)이나 엣지(Edge) 등 웹 브라우저를 켜고 주소창에 아래 주소를 입력하여 접속합니다:
👉 **`http://localhost:3000`**

## ☁️ Vercel에 배포하는 방법

1. GitHub 저장소에 코드를 푸시합니다. (`.env` 파일은 `.gitignore`에 등록되어 자동으로 보호됩니다.)
2. [Vercel 대시보드](https://vercel.com)에서 **`Add New...` > `Project`**를 클릭하고 저장소를 가져옵니다(Import).
3. **Environment Variables (환경 변수)** 설정에서 아래 항목들을 등록합니다:
   - `OPENAI_API_KEY`: 실제 OpenAI API 키
   - `OPENAI_MODEL`: `gpt-4o-mini`
4. **Deploy** 버튼을 누르면 몇 초 안에 전 세계 어디서나 접속할 수 있는 웹사이트가 완성됩니다!
